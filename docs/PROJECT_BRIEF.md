# Project brief: raakthh portfolio

## Goal
A complete, modern, professional, recruiter-focused personal portfolio for the brand **raakthh** (always lowercase).

- Tagline: "Building with data. Thinking beyond it."
- Intro: "I'm Araa, a Data Science student exploring analytics, machine learning, data engineering, and practical software solutions."

## Stack and constraints
HTML5, CSS3, vanilla JavaScript. Lightweight, responsive, easy to maintain, GitHub Pages compatible. No heavy frameworks or unnecessary dependencies. Relative asset paths. No secrets.

## Design
Modern and minimal. Dark navy, cyan, white, soft gray. Dark/light mode, subtle animations, rounded cards. Avoid heavy gradients, neon effects, fake skill percentages, and decoration.

## Sections and features
Home, About, Projects, Experience, Skills, Contact, Footer. Sticky navbar, mobile hamburger menu, smooth scrolling, active nav state, project category filters (All, Data Science, Data Analytics, Data Engineering, AI, Web Development), project detail modal, theme toggle saved in localStorage, reveal animations, back-to-top button.

## Content rules
- Projects: SAVERA, NOVA AI, AprioriRec, SmartSales with the exact links provided (SahabatStok was removed at the owner's request). SmartSales has no links. Nothing invented.
- Experience: Firzzy Store (Owner), Dirgantara (Head of Media & Information Division), Program Studi Sains Data Terapan (Social Media Specialist). No dates or results invented.
- Skills: four categories shown as tags, no percentages.
- Contact: email, WhatsApp, GitHub, LinkedIn cards. No contact form.

## Assets
Profile photo at `assets/images/profile/profile.jpg`, project screenshots in `assets/images/projects/`, CV at `assets/documents/cv.pdf` (button hidden until it exists), favicon at `assets/favicon.svg`. Placeholders only; no fake photos, CV, or screenshots.

## Technical requirements
Semantic HTML, accessible labels, responsive layout, SEO metadata, favicon, `prefers-reduced-motion`, keyboard accessibility with visible focus, centralized content in `js/data.js`.

## Documentation
`README.md`, `docs/PROJECT_BRIEF.md`, `docs/PROGRESS.md`.
